# 11月分進捗
## 操作方法
WASDで移動。  
マウスで狙って左クリックで攻撃（長押しで連射）  
## 今月の成果一覧
- ファンネル
  - ファンネルの攻撃方法を実装することに成功
- ファンネルの回転
  - 敵の周りをファンネルが周回するような動きを実装することに成功
- 被弾時の状態
  - 敵が被弾したときに点滅して当たったかどうかが分かるようになった

## その他
先月より当たり判定を調整し、より敵に弾が当たるように調整しています。
プレイヤーの連射が強すぎるので5連射になるよう調整いたしました。
敵に攻撃を当てた時に点滅させることでダメージを与えてる感触を表現しています。
敵の攻撃を3つほど作る予定でしたが他の実装に思ったより時間がかかってしまったため、12月中に実装しようと思います。
